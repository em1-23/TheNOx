# 🖥️ NOX — Personal Portfolio & Digital Hub

> **One place. Everything NOX.**

**NOX** is a modern personal digital hub built to represent **everything about me as a developer** — my skills, projects, experience, experiments, goals, and the things I'm currently building.

It isn't just a portfolio.

It's my **digital identity**.

---

## ✦ About NOX

NOX is designed as a centralized website where everything related to me and my work lives in one place.

Instead of having separate pages scattered across different platforms, NOX brings everything together into a single modern interface.

### Inside NOX

* 👤 About Me

# 🎨 Design Philosophy

NOX follows a modern **developer-focused UI**.

The interface should feel:

* Dark
* Minimal
* Futuristic
* Fast
* Clean
* Interactive
* Developer-oriented

The goal isn't to make the website complicated.

The goal is to make it feel like:

> **"This is someone's entire digital world."**
